# Детектор аритмий ЭКГ — прошивка для STM32F4

Прошивка вокруг того же `no_std`-ядра (`ecg-core`), что и хостовая версия.
Ядро **не менялось** — прошивка лишь даёт ему отсчёты и на события зажигает
«тревогу» + пишет лог в UART.

По умолчанию — **STM32F407 Discovery** (Renode знает эту плату из коробки)!!!
Как собрать под другой камень — в конце.

## Структура

    ecg-core/          ← ядро (no_std, целочисленное) — БЕЗ ИЗМЕНЕНИЙ
    ecg-fw/            ← прошивка
      src/main.rs        setup + цикл push → тревога + лог, замер тактов (DWT)
      src/source_test.rs источник: зашитая запись .v1  (фича test-data)
      src/source_adc.rs  источник: АЦП + таймер 250 Гц (фича adc, только железо)
      src/ecg_data.rs    зашитая запись (сгенерирована из run5.v1)
      memory.x           карта памяти камня (flash/RAM)
    gen_data.py        ← перегенерить ecg_data.rs из любого .v1
    ecg.resc           ← скрипт запуска в Renode

## Два режима входа (выбираются фичей на этапе компиляции)

    test-data  зашитая запись .v1 — для Renode / без железа (по умолчанию)
    adc         реальный сигнал с АЦП (PA1) + таймер 250 Гц — только на плате

## Что нужно поставить (один раз)

    rustup target add thumbv7em-none-eabihf          # ядро Cortex-M4F
    # для замеров размера:
    cargo install cargo-binutils && rustup component add llvm-tools

## Сборка

    # для Renode / без железа:
    cargo build --release --features test-data

    # для реальной платы (сигнал с АЦП):
    cargo build --release --no-default-features --features adc

ELF окажется в `target/thumbv7em-none-eabihf/release/ecg-fw`.

## Запуск в Renode

    renode ecg.resc      # откроется монитор Renode + окно логов USART2
    (Renode) start       # если не раскомментировал `start` в скрипте

Красный светодиод (PD14) загорается как «тревога» на пробежки/куплеты. хз нужно ли это? 

Про такты: Renode — НЕ потактовый эмулятор, он считает инструкции, поэтому
`тактов/push` в Renode это грубый ориентир. Точные такты — только на живом
чипе (там DWT считает реальные циклы ядра). Если показывает ~0 — в этой сборке
Renode нет модели DWT, тогда меряй размер здесь, а такты на плате.

## Померить flash и ОЗУ (точно, из слинкованного бинаря)

`.text`+`.rodata` → flash, `.data`+`.bss` → ОЗУ. Если прошивка не влезет в
регионы из `memory.x` — линкер упадёт ещё при сборке.
Текущие данные что 40 Кб занимет вся прошивка из которых ~6,8 КБ это алгоритм 
остальное тестовые данные что загнал для проверки да таблица прерывания с инитом
## Заливка на реальную плату

    cargo install probe-rs-tools
    cargo run --release --no-default-features --features adc   # если включил runner в .cargo/config.toml
    # либо вручную:
    probe-rs run --chip STM32F407VGTx target/thumbv7em-none-eabihf/release/ecg-fw

Лог USART2 (PA2) смотреть USB-переходником, либо переключить лог на RTT
(быстрее; см. комментарии в main.rs). DWT-такты на плате — уже настоящие.

Меняется ТОЛЬКО тонкий слой обвязки; ядро и логика — ноль правок.


## Известное ограничение сборки

`ecg-core` и `src/ecg_data.rs` проверены компилятором. Сам firmware
(`main.rs`, `source_adc.rs`) писался под API `stm32f4xx-hal 0.23` по свежим
примерам, но кросс-сборка под ARM в моём окружении недоступна — возможны
мелкие правки имён HAL на первом `cargo build`. Самый вероятный кандидат —
`source_adc.rs` (сигнатуры АЦП/таймера); режим `test-data` минимален и
использует только подтверждённые примерами вызовы.
